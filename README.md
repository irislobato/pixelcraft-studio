# Pixelcraft Studio 🎨💻

> **Pixelcraft Studio** 🎨 E-commerce nostálgico que une arte feita à mão com a estética Y2K de interfaces clássicas. Projeto front-end responsivo construído com HTML, CSS e JS puro, com foco no uso de variáveis CSS, animações e uso de LocalStorage.

![Status do Projeto](https://img.shields.io/badge/Status-Concluído-success?style=for-the-badge)

## 📌 Sobre o Projeto

Este projeto é um desafio prático de Front-End para a construção de um site comercial completo. A proposta foi criar o **Pixelcraft Studio**, uma loja virtual fictícia que vende artes feitas à mão. O diferencial do projeto é a sua identidade visual: o layout emula janelas de sistemas operacionais do início dos anos 2000 (estética Y2K), oferecendo uma experiência nostálgica e lúdica sem perder a legibilidade e a usabilidade moderna.

A loja conta com a presença da mascote **Giga the Cat**, uma gatinha digital que acompanha o usuário pela interface.

## 🚀 Funcionalidades

- **Estrutura Completa:** Possui `Hero Section` temática, `Navbar` (estilo barra de tarefas) e `Footer`.
- **Design System Customizado:** Gerenciamento total de cores e fontes através de **CSS Variables** (`:root`), garantindo facilidade na manutenção do código.
- **Animações Fluidas:** Efeitos visuais e animações CSS nos elementos interativos (botões e cards de produtos).
- **Armazenamento Local:** Implementação de um banner de cookies interativo, estilizado como uma caixa de aviso de sistema antigo. O aceite é gerenciado com JavaScript puro e salvo no `LocalStorage` do navegador.
- **Totalmente Responsivo:** Design adaptável para computadores, tablets e celulares utilizando *Media Queries*.

## 🎨 Identidade Visual (Design System)

O visual foi planejado para equilibrar o ruído da internet dos anos 2000 com um design limpo:
- **UI/UX Concept:** Caixas com formato de janelas com fundo liso (*Oatmeal Paper*) para 100% de legibilidade, isolando texturas (*CRT Scanlines*) nas bordas.
- **Paleta de Cores (Cyber-Craft):** Uma base neutra de *Ink Black* e *Oatmeal Paper*, contrastada com detalhes vibrantes como *Candy Magenta* e *Lime Slime*.
- **Tipografia:**
  - `JetBrains Mono`: Para cabeçalhos, botões e elementos de "sistema".
  - `Inter`: Para corpo do texto, visando leitura fluida.
  - `Caveat Brush`: Detalhes manuais para reforçar o estilo "Handcrafted".

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica.
- **CSS3:** Flexbox, CSS Grid, Variáveis CSS (`:root`), Keyframes/Animações e Media Queries.
- **JavaScript (Vanilla):** Manipulação de DOM e gerenciamento de LocalStorage.
